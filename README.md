# Интендант — бот клан-чата Raid: Shadow Legends

Telegram-бот на aiogram 3 + SQLite. Голос — интендант вольного отряда наёмников:
ведёт учёт людей, ворчит и гоняет за несданными отчётами.

Три механики:

1. **Напоминалки** — только про Гидру и Химеру, по два раза на каждое событие.
2. **Шутки** — 2–3 раза в день в случайный момент, иногда с тегом участника.
3. **Развлечения чата** — герой/клоун дня, предсказания, крокодил, вордл,
   викторина, русская рулетка, кости и слоты, монеты.

> **Мини-RPG выключена** (походы, дуэли, профиль). Код остался в `bot/game/`
> и `bot/handlers/{rpg,raid,duel}.py`, её разделы ниже описывают выключенную
> механику. Вернуть — подключить роутеры и команды в `bot/main.py`.

## Быстрый старт

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

cp .env.example .env      # вписать BOT_TOKEN и CLAN_CHAT_ID
.venv/bin/python -m bot.main
```

База данных создаётся сама при первом запуске.

### Где взять значения для .env

**BOT_TOKEN** — у [@BotFather](https://t.me/BotFather): `/newbot` или `/mybots` →
нужный бот → API Token.

**CLAN_CHAT_ID** — позовите бота в группу и выполните там `/chatid`.
Он ответит числом вида `-1003799181757`. Пока переменная пуста, бот работает,
но напоминалки и шутки отключены — в лог падает предупреждение.

### Обязательный шаг: отключить privacy mode

По умолчанию бот **не видит обычные сообщения в группе** — только команды.
Из-за этого он не соберёт список участников, и адресные шутки будет некому
адресовать. Лечится любым из двух способов:

- @BotFather → `/mybots` → ваш бот → Bot Settings → Group Privacy → **Turn off**
- либо выдать боту права администратора в группе — на админов privacy не действует

## Команды

| Команда | Что делает |
|---|---|
| `/hero`, `/clown` | Герой и клоун дня — раз в сутки на чат, с подводкой и тегом |
| `/who <вопрос>` | «Кто сегодня…» — случайный участник (`/who сливает ключи`) |
| `/predict`, «гадание», «погадай» | Гадание на день — одно на человека, перезапрос не меняет. 1000 вариантов |
| `/croc` | Крокодил: ведущий смотрит слово во всплывашке и объясняет, чат угадывает обычными сообщениями. 3 минуты, 3 замены слова. +15 🪙 угадавшему, +10 ведущему |
| `/wordle`, `/w слово` | Вордл на весь чат: существительное из 5 букв, 6 попыток на всех. Угадавшему 60…10 🪙 по номеру попытки |
| `/quiz` | Вопрос викторины нативным quiz-опросом, 30 секунд, +10 🪙 за верный |
| `/roulette` | Русская рулетка на 2–6 человек: лобби, курок по очереди, патрон один |
| `/roll [ставка]` | Кости: ответом на сообщение — вызов ему, без ответа — открытый вызов. Со ставкой победитель забирает обе |
| `/slots [ставка]` | Слоты 🎰. Тройка семёрок ×15, другая тройка ×5, две семёрки ×2 (матожидание 0.75). Брошенный руками 🎰 тоже комментируется |
| `/daily` | Ежедневные 50 🪙. На старте у каждого 100 |
| `/balance` | Сколько монет |
| `/give N` | Перевести монеты — ответом на сообщение получателя |
| `/rich` | Самые богатые |
| `/top` | Доска почёта: герои, клоуны, викторина, кости, джекпоты, рулетка |
| `/start` | Записаться в реестр отряда |
| `/init` | Перепись отряда: кнопка «Я в деле» + запись всех админов чата |
| `/chatid` | Узнать ID чата. Нужна один раз при настройке |
| `/help` | Справка |

Кандидаты в «X дня» и `/who` — все, кого бот знает: нажавшие кнопку в `/init`
и любой, кто писал в чат. Кости и слоты — нативный `sendDice`: значение
выдаёт сервер Telegram, бот его не выбирает. Вопросы викторины —
`bot/content/quiz/questions.txt`, тексты `/who` и `/predict` —
`bot/content/phrases/fun/`.

**Словари** — `bot/content/words/`: 2839 слов крокодила, 633 загадки вордла
и 3409 допустимых догадок (все пятибуквенные существительные). Собраны из
[Harrix/Russian-Nouns](https://github.com/Harrix/Russian-Nouns) (MIT), отобраны
по частоте [FrequencyWords](https://github.com/hermitdave/FrequencyWords)
(CC BY-SA 4.0), отфильтрованы pymorphy3 и вычищены от мата и грубостей вручную.
Слово можно просто дописать или удалить строкой.

**Крокодилу нужен выключенный privacy mode** (или бот-админ): догадки — обычные
сообщения. Остальные игры работают через команды и кнопки.

## Что видит клан, а что нет

Всё происходит прямо в клан-чате, но содержимое боя видит только участник:
оно приходит **всплывающим окном**, которое Telegram показывает исключительно
нажавшему кнопку. В самом чате висит нейтральный статус.

**Поход.** В чате всё время висит одна неизменная строка —
`🐺 Волчий лес · Дмитрий в подземелье` — и кнопки. Ни шага, ни здоровья:
по сообщению нельзя следить за чужим боем и понять, сколько ему осталось.
Меняются только сами кнопки, когда бой сменяется развилкой. Во всплывашке
у игрока: чей ход против чьего, описание, урон и остаток здоровья обеих сторон.
По возвращении строка заменяется сводкой — кого убил, что нашёл, сколько опыта.

**Дуэль.** Вызов, принятие и итог видят все, между ними — `Бой идёт, ходы
делают втайне`, без номера раунда и без здоровья. Раунды приходят всплывашками
двоим участникам. Тот, кто нажал первым, видит итог раунда со следующим своим
нажатием: всплывашка появляется только в ответ на действие.

Всплывашка обрезается на **200 символах** — весь формат подогнан под это,
и лимит проверяется тестами на самых длинных именах и худших раскладах.

Нажать чужую кнопку нельзя: в каждой зашит владелец, чужому бот ответит отказом.

## Как это играется

**Бой — камень/ножницы/бумага.** Оба выбирают одновременно, вскрывается разом:

```
🛡️ Парирование  бьёт  ⚔️ Удар
⚔️ Удар         бьёт  🗡️ Укол
🗡️ Укол         бьёт  🛡️ Парирование
```

Одинаковые приёмы — ничья: урона не получает никто. Урон наносит только
победитель раунда, по формуле `АТК × 50 / (50 + защита противника)`
с разбросом ±10%. Кольцо задано одним словарём `BEATS` в `bot/game/combat.py`,
матрица множителей собирается из него.

**Статы решают через пороги.** Исход раунда от характеристик не зависит вовсе —
это чистая монетка. Зависит другое: сколько выигранных раундов нужно, чтобы снять
противника (`Ka`), и сколько ему, чтобы снять тебя (`Kb`). Шанс победы — функция
только от этой пары:

```
Ka\Kb    1      2      3      4      5
  1    50.0%  75.0%  87.5%  93.8%  96.9%
  2    25.0%  50.0%  68.8%  81.2%  89.1%
  3    12.5%  31.2%  50.0%  65.6%  77.3%
  4     6.2%  18.8%  34.4%  50.0%  63.7%
```

Отсюда и роли характеристик: **атака** снижает `Ka` ступенями, **здоровье**
плавно поднимает `Kb`, **защита** делит входящий урон и потому множится
со здоровьем. Числа маленькие намеренно: при десятке HP одно очко переводит
бой из проигрышного в выигрышный, при сотне — не значит ничего.

**Пять подземелий, каждое на свои четыре уровня.**

| Подземелье | Уровни | Этажи |
|---|---|---|
| 🐀 Крысиная нора | 1–4 | Облезлая крыса · Крыса-падальщик · Крысиный вожак |
| 🐺 Волчий лес | 5–8 | Молодой волк · Матёрый волк · Вожак стаи |
| 🕷 Паучьи катакомбы | 9–12 | Пещерный паук · Ткачиха · Матка выводка |
| 💀 Курган мертвецов | 13–16 | Костяной ратник · Могильный упырь · Курганный владыка |
| 🔥 Логово | 17–20 | Огненный бес · Надсмотрщик · Владыка логова |

Кривая одна на все подземелья и считается по этажам. Придя на входном уровне,
игрок уверенно берёт первый этаж, второй проходит изредка, до третьего почти
не добирается. Каждый уровень внутри локации сдвигает эту границу вниз:

```
🐀 Крысиная нора      погиб на 1-м   дошёл до 1   до 2    прошёл всё
  ур.1                   31.1%         61.4%      7.4%       0.2%
  ур.2                    7.3%         68.7%     22.9%       1.1%
  ур.3                    3.7%         59.0%     34.2%       3.2%
  ур.4                    1.5%         50.5%     42.0%       6.0%
```

Локации разведены и между собой: пройдя нору до конца, на первом этаже леса
игрок получает 31%, а не «как у себя дома». Иначе уровни в кнопках были бы
украшением.

**Соваться выше уровня не запрещено, но дорого.** Волк сносит новичка с одного
попадания. Кнопка подписана вердиктом — `🎯 по уровню`, `✅ по силам`,
`☠️ смертельно`, — а в `/profile` есть раздел «Куда идти» с шансом взять
каждый этаж на текущих характеристиках.

**У подземелья нет дна.** Три этажа — это его собственные твари; ниже ждёт
та же последняя, но матёрая: за каждый этаж вглубь ей множатся все
характеристики (×1.25), а цена растёт медленнее (×1.15). Поэтому нырять
глубже выгодно, но не бесконечно — риск обгоняет награду, и перекачанному
игроку всё равно выгоднее идти в подземелье по своему уровню, чем вечно
полоскать крысиную нору:

| Игрок 20 уровня | Опыта за поход | Этажей |
|---|---|---|
| 🐀 Крысиная нора | 18.2 | 6.0 |
| 🐺 Волчий лес | 25.1 | 3.8 |
| 🔥 Логово (его уровень) | 23.8 | 1.4 |

**Уйти можно после любого этажа.** Здоровье между этажами не
восстанавливается, поэтому каждый следующий встречается на том, что осталось.
Отсюда единственное настоящее решение похода — жадность.

Числа — вслепую, без знания повадок: так считается весь баланс. Повадки идут
сверху как награда за внимательность, закладываться на них нельзя.

**У каждой твари свои повадки** — постоянные веса выбора. В каждой локации есть
противник под каждый ответ, так что «жать одну кнопку» не выйдет.

**Находки** вместо инвентаря: предмет навсегда прибавляет характеристику.
Шанс 10% пока предмета нет и 5% на повторный, до предела в 3 штуки.

**Дуэль** — 5 раундов, энергию не тратит. Победа по доле оставшегося здоровья,
а не по абсолюту. Опыт начисляется за первые 5 дуэлей в сутки.

**Опыт — по глубине, а не по числу побед.** Тварь стоит столько, на каком
уровне она стоит: этажи норы дают 1/2/3, этажи логова — 17/18/19. Поэтому
фарм лёгкой локации бессмыслен: пройти нору целиком на 20 уровне это 6 опыта
против 54 за логово. Опыт за дуэль — уровень соперника (половина при
поражении), не больше пяти дуэлей в сутки.

**Пороги растут круче дохода** — `round(L^2.4) + L`, подобрано под реальную
добычу из подземелий:

| Уровень | Нужно опыта | Это примерно |
|---|---|---|
| 1 → 2 | 2 | первый же день, две победы |
| 2 → 3 | 7 | два дня |
| 5 → 6 | 53 | неделя |
| 10 → 11 | 261 | две недели |
| 19 → 20 | 1191 | месяц |

Весь путь с первого до двадцатого — около 10 месяцев при двух походах в день.
За уровень +3 HP, +1 атака и +1 защиты через уровень; вся арифметика уровней
собрана в `bot/game/progression.py`.

## Как править содержимое

Тексты лежат отдельно от кода, одна строка — одна фраза. Строки с `#`
и пустые игнорируются, так что их можно использовать как заголовки блоков.

```
bot/content/phrases/
  jokes/general.txt          300 безадресных шуток
  jokes/personal.txt         200 адресных — в каждой обязателен {mention}
  reminders/hydra.txt         30 про Гидру
  reminders/chimera.txt       30 про Химеру
```

В напоминалках `{when}` разворачивается в срок конкретной отправки —
«в среду утром», «завтра в 14:30», «через 2 часа», — поэтому фраза должна
читаться с любым из них. После правки перезапустите бота: файлы читаются
один раз и кешируются.

**Расписание** — в `bot/content/reminders.py`. Одна строка — один момент
отправки: день недели, время по `TZ` и то, как назвать срок в тексте:

```python
Reminder(key="hydra", weekday=WED, at=time(9, 0), when="через 2 часа"),
```

Что и когда шлётся сейчас:

| Событие | Когда происходит | Напоминания |
|---|---|---|
| Гидра | обновляется в среду, 11:00–16:00 МСК (08:00–13:00 UTC) | вторник 11:00 (за сутки) и среда 09:00 |
| Химера | бои закрываются в четверг в 14:30 МСК | среда 14:30 (за сутки) и четверг 12:30 |

Ориентир для Гидры — начало окна обновления: после 11:00 ключи уже могут
сгореть, поэтому «за 2 часа» отсчитано от него.

Новое событие: добавить строки сюда и создать файл `reminders/<key>.txt`.

**Монстры, локации и находки** — в `bot/game/world.py`.

## Постоянный запуск

Бот, запущенный из терминала, умрёт вместе с сессией. Для постоянной работы:

```bash
sudo cp deploy/rpg-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now rpg-bot
```

Юнит рассчитан на то, что проект лежит в `/home/brzhkv/Custom/rpg`, — если путь
другой, поправьте `WorkingDirectory` и `ExecStart`.

```bash
systemctl status rpg-bot          # состояние
journalctl -u rpg-bot -f          # живой лог
sudo systemctl restart rpg-bot    # после правки текстов или кода
```
